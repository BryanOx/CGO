# Common assets

Cross-game resources belong here. Licensed audio lives in the `audio/`
subfolder; fonts remain a gate note only.

All 17 licensed audio assets now live under `res://assets/common/audio/` (13 CC0
Kenney effects with SHA-256 proof and 4 owner-declared CC0 HoliznaCC0 tracks);
see `docs/adr/0006-asset-license-policy.md`; no audio file belongs directly in
this folder. Any future font must likewise have a documented commercial license
before its file is copied here.

Acquisition tier remains metadata. Prices and availability are server authority,
and stable IDs never come from filenames.
