# Card assets

Card artwork is grouped by game and deck identifier. Each ingested deck keeps
its manifest, attribution, and optimized PNGs together so provenance survives
export compression and file renames.

The first entry is `conga/classic_red/`: 50 PNGs at 160x247, copied verbatim from
the read-only `congauy` source with its manifest and CC BY-SA 3.0 attribution.
`back.png` serves as the local preview image; no atlas or preview derivative was
generated because the individual PNGs are already optimized.

Stable IDs come from catalog metadata, never from filenames. Acquisition tier is
metadata only; prices and availability are server authority. Audio stays
excluded until a license decision is made.
